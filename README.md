Общие предусловия: пользователь авторизован в приложении Android, интернет работает, если не указано другое.

### Проверка формата и размера

**TC-001. Установка JPEG**

Предусловия: есть JPEG-фото размером 3 МБ, лицо человека хорошо видно.

Шаги:
1. Открыть профиль.
2. Перейти к изменению аватара.
3. Выбрать фотографию.
4. Подтвердить установку.

Ожидаемый результат: фотография загружается и отображается в профиле.

**TC-002. Установка PNG**

Предусловия: есть PNG-фото размером 3 МБ, подходящее под требования.

Шаги:
1. Открыть изменение аватара.
2. Выбрать PNG-фото.
3. Подтвердить установку.

Ожидаемый результат: фотография успешно устанавливается, ошибок нет.

**TC-003. Проверка границы 5 МБ**

Предусловия: подготовлены JPEG и PNG фотографии размером 5 МБ - 1 байт, ровно 5 МБ и 5 МБ + 1 байт. Остальные требования соблюдены.

Шаги:

2. Попробовать загрузить JPEG каждого размера.

Ожидаемый результат: файлы до 5 МБ включительно принимаются, файлы больше 5 МБ отклоняются с ошибкой.

Шаги:

3. Попытаться установить.

Ожидаемый результат: файл не принимается, появляется ошибка формата.

**TC-005. Повреждённая фотография**

3. Попытаться загрузить.

Ожидаемый результат: файл не загружается, приложение не зависает и не вылетает.

**TC-006. Несоответствие расширения**

Ожидаемый результат: приложение определяет, что внутри неподдерживаемый формат, и не устанавливает аватар.

**TC-012. Замена старого аватара**

### Интернет и ошибки

**TC-016. Загрузка без интернета**

Предусловия: есть подходящая фотография, интернет отключён.

Шаги:
1. Открыть изменение аватара.
2. Выбрать фотографию.
3. Попытаться загрузить.

Ожидаемый результат: приложение сообщает о проблеме с соединением, не зависает. Если загрузка не выполнена, старый аватар остаётся.

**TC-017. Отключение интернета при загрузке**

Предусловия: есть подходящая фотография, интернет работает.

Шаги:
1. Открыть изменение аватара.
2. Начать загрузку фотографии.
3. До окончания загрузки выключить интернет.
4. Проверить реакцию приложения.
5. Включить интернет обратно.

Ожидаемый результат: приложение не зависает и корректно обрабатывает потерю соединения. Если загрузка не завершилась, успех не отображается. Повторная попытка должна быть возможна.

**TC-018. Неподходящая фотография и смена сети**

Предусловия: подготовлена фотография без лица, интернет включён.

Шаги:
1. Открыть изменение аватара.
2. Попытаться загрузить фотографию.
3. Отключить интернет и включить обратно.
4. Проверить, получится ли установить фотографию.

Ожидаемый результат: фотография всё равно не должна проходить проверку. Если файл был отклонён ещё до загрузки, это тоже правильный результат.

**TC-019. Ошибка сервера**

Предусловия: у пользователя есть аватар и подготовлена новая фотография. Есть возможность вызвать ошибку сервера 500.

Шаги:
1. Открыть изменение аватара.
2. Выбрать новую фотографию.
3. Начать загрузку.
4. Воспроизвести ошибку сервера.
5. Проверить сообщение и аватар.

Ожидаемый результат: приложение сообщает об ошибке, а не об успешной загрузке. Нужно проверить, изменился ли аватар на сервере и в приложении.

### Дополнительные проверки

**TC-020. Разрешения Android**

Предусловия: приложению не предоставлен доступ к фотографиям.

**TC-022. Проверка через API**

Предусловия: есть доступ к API загрузки аватара и авторизация. Подготовлен обычный текстовый файл с расширением .jpg.

## Задание 4. Использованные техники тест-дизайна

**1. Классы эквивалентности**

Разделил данные на группы, которые должны обрабатываться одинаково. Например, разрешённые форматы JPEG и PNG и неподдерживаемые форматы GIF, BMP. Также фотографии с хорошо видимым лицом и фотографии, которые не подходят под требования.

**2. Анализ граничных значений**

Использовал при проверке ограничения размера файла в 5 МБ. Для JPEG и PNG взял три значения: 5 МБ - 1 байт, ровно 5 МБ и 5 МБ + 1 байт. Так можно проверить, правильно ли работает ограничение на размер.

**3. Тестирование переходов состояний**

Проверял, как меняется состояние приложения при разных действиях. Например, замена старого аватара новым, сохранение старого при неудачной загрузке, отключение и восстановление интернета во время загрузки.

**4. Предугадывание ошибок**

Добавил проверки, в которых могут возникать ошибки: повреждённые фотографии, несовпадение расширения и содержимого файла, несколько быстрых нажатий на кнопку установки, попытка обойти проверку через API или при отключении интернета.

Также использовал позитивные и негативные проверки: загрузку подходящих фотографий и попытки загрузить файлы, которые нарушают требования.
