## Задание 1. Сценарии тестирования

**Позитивные сценарии:**

1. Успешная загрузка фотографии формата JPEG, соответствующей всем требованиям.
2. Успешная загрузка фотографии формата PNG, соответствующей всем требованиям.
3. Установка фотографии размером ровно 5 МБ.
4. Замена ранее установленного аватара новым.

**Негативные сценарии:**

5. Попытка загрузки файла неподдерживаемого формата.
6. Попытка загрузки фотографии размером более 5 МБ.
7. Загрузка изображения без лица человека или с нечётко видимым лицом.
8. Попытка загрузки изображения, сгенерированного ИИ.
9. Загрузка повреждённого файла или файла, расширение которого не соответствует содержимому.
10. Попытка загрузки потенциально вредоносного файла под видом изображения.

**Сценарии работы приложения:**

11. Загрузка фотографии при отсутствии интернет-соединения.
12. Потеря интернет-соединения непосредственно во время загрузки.
13. Отмена выбора фотографии или процесса загрузки.
14. Проверка сохранения установленного аватара после перезапуска приложения и повторного входа в аккаунт.
15. Проверка поведения приложения при предоставлении и отказе в разрешении на доступ к фотографиям на Android.



## Задание 2. Чек-лист

**Проверка формата и размера файла**

- Успешная загрузка фотографии JPEG.
- Успешная загрузка фотографии PNG.
- Загрузка JPEG размером 5 МБ − 1 байт.
- Загрузка JPEG размером ровно 5 МБ.
- Загрузка JPEG размером 5 МБ + 1 байт.
- Такие же три проверки размера для PNG.
- Попытка загрузить неподдерживаемый формат, например GIF.
- Загрузка повреждённой фотографии.
- Загрузка файла, у которого расширение не соответствует реальному формату.

**Проверка содержимого фотографии**

- Загрузка фотографии, на которой вообще нет человека.
- Загрузка фотографии с размытым лицом.
- Загрузка фотографии с закрытым лицом.
- Попытка загрузить фотографию, сгенерированную ИИ.
- Загрузка фотографии после редактирования в Photoshop или другом редакторе.

**Установка и замена аватара**

- Успешная замена старого аватара на новый.
- Попытка заменить аватар фотографией, которая не проходит проверку.
- Проверка, что старый аватар не пропал после неудачной замены.
- Проверка сохранения нового аватара после перезапуска приложения.
- Отмена выбора фотографии.

**Проверка интернета и ошибок**

- Попытка загрузить подходящую фотографию без интернета.
-  Отключение интернета прямо во время загрузки.
- Восстановление интернета после прерывания загрузки.
- Попытка загрузки неподходящей фотографии с отключением и повторным включением интернета. Проверить, не получится ли обойти валидацию.
- Проверка поведения приложения при ошибке сервера.

**Дополнительные проверки**

- Проверка работы выбора фотографии при отказе в разрешении Android, если приложение запрашивает такой доступ.
- Несколько быстрых нажатий на кнопку установки аватара.
- Проверка сообщений об ошибках при неудачной загрузке.
- Попытка отправить неподходящий файл напрямую через API, например через Postman, если есть доступ к API.
